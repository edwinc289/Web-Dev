Web Technologies

HTML

HTML is a Hyper Text Markup Language, which brings the elements into the webpage. It includes angle brackets and is pure text-based. The browser receives the HTML file and renders the web page.

CSS

CSS is coding language that styles the elements. Used to determine the visual presentation, layout, and design.

JavaScript

JavaScript is a versatile, high-level programming language primarily used to add interactivity, dynamic behavior, and complex features to websites.
